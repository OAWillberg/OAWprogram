OAWProgram – yksinkertainen ylläpito

index.html = julkinen sivu
admin.html = ylläpitosivu
data/texts.json = päivän tekstit

Ylläpidossa valitset päivän, kirjoitat otsikon ja tekstin ja painat Tallenna.
Sen jälkeen paina Lataa valmis texts.json ja korvaa GitHubissa data/texts.json sen sisällöllä.

GitHub Pages ei salli ylläpitosivun kirjoittaa suoraan repositoryyn ilman erillistä palvelua.
